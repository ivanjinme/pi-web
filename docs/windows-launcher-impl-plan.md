## 最小 npm 运行策略与核心检查（代码及当前损坏环境恢复已通过）

- 用户重新确认：先避免人为中断 npm，正常安装／重试交给 npm；不自建续传或自动清理半成品机制。

- 不自动删除 node_modules、锁文件或 npm 缓存，不单补 isexe，不硬编码 CDN IP、不改 TUN。已观察到旧版空目录及 API 500，但“超时直接导致空目录”的因果尚未独立证明。
