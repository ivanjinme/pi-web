# Weclio

[English](./README.md)

基于 [Pi 编程智能体](https://github.com/badlogic/pi-mono)构建的 harness，提供 Web 和 Desktop 双入口。

## 快速开始

```bash
npx @weclio/pi-web@latest
# 或
npm install -g @weclio/pi-web
weclio-web
```

打开 http://127.0.0.1:8888（浏览器会自动打开）。

## 开发

```bash
npm install
npm run dev           # 桌面（默认）
npm run dev:desktop   # 桌面
npm run dev:web       # Web
```
