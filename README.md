# Weclio

[中文](./README.zh-CN.md)

An agent harness built on [Pi](https://github.com/badlogic/pi-mono), with a web UI and desktop app.

## Quick Start

```bash
npx @weclio/pi-web@latest
# or
npm install -g @weclio/pi-web
weclio-web
```

Open http://127.0.0.1:8888 (the browser opens automatically).

## Development

```bash
npm install
npm run dev           # Desktop (default)
npm run dev:desktop   # Desktop
npm run dev:web       # Web
```
